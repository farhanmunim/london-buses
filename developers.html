londonbuses.org API

Open data on London's bus network as plain JSON. No key, no sign-up, CORS-enabled — call it from a browser, a script or a server. It is the same data the website runs on.

Quick start

curl https://londonbuses.org/api/v1/routes/88.json
curl https://londonbuses.org/api/v1/line-status.json
curl "https://londonbuses.org/api/v1/live/vehicles?line=88"

Every response is an envelope: { "meta": { version, resource, generatedAt, source, attribution[] }, "data": … }. meta.generatedAt tells you how fresh the data is; /api/v1/manifest.json lists every dataset's source and update cadence.

Using it fairly

  • Attribution is required. Keep the credits in meta.attribution (or the list below) visible wherever you show the data.
  • Be kind to the cache. Responses revalidate (ETag / 304) so polling is cheap — but data only changes every few hours, so poll accordingly. meta.generatedAt and the manifest show cadence.
  • Stable within v1. Fields are only added, never removed or retyped. Breaking changes ship as /api/v2, with v1 kept running for a long overlap.
  • Provided as is, without warranty. Not affiliated with Transport for London or any operator. Live bus positions are capped at one request per route every 10 seconds.
